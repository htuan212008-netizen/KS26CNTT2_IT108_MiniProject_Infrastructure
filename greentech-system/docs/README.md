# Hệ thống Quản trị Hạ tầng GreenTech

Hệ thống tự động hóa quản lý nhật ký (Log) và hạ tầng thiết bị IoT cho trang trại thông minh.

## Hướng dẫn Chạy Script Tự động hóa

Để chạy robot lọc log sự cố, thực hiện lệnh từ thư mục `scripts/`:

```powershell
cd ./scripts
./auto_report.bat
```
## Kiếm tra thiết bị
- [x] Khởi tạo cấu trúc cây thư mục 3 cấp
- [ ] Kiểm tra kết nối mạng 10m Ugreen Cat6/Cat8
- [ ] Cấu hình biến môi trường `.env`
- [x] Chạy script lọc log tự động
